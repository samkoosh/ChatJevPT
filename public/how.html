How ChatJevPT works

Jev doesn't write text. It answers typed questions with probabilities. ChatJevPT asks it, over and over, what the next character of the answer should be, and appends the winner. The four levels ("dumb as a ___") differ in how they ask.

Admin: every prompt under "What Jev is told" is editable here. Save for everyone applies it to everyone's answers within 15 seconds; Reset to default puts the original back. Stump's screening, checks and ranking prompts are shared with Post.

The loop, at every level

The browser drives it: one request per character, so the answer types out live and Stop is instant. Each request goes through the chosen level, which returns one character, or END.

Browser sends the question, the answer so far and (with memory on) earlier turns
The level picks the next character (sections below)
Is it END? Yes → answer finished
Append the character and show it
200 characters reached? Yes → answer finished
No → ask again for the next character

When the answer finishes, one more Jev call grades it (see Rating).

Doornail the naive one

One Choice per character over every character: A–Z, 0–9, a space, a line break, . , ! ? : ; ' - and, once something is written, END. Each option is labelled with the character itself (a space is labelled "space") and described in one line, like "The letter A." Jev sees only the question and the answer so far. The most probable option wins; a tie is a coin flip.

No word list, no rules, no checks, no memory. Whatever Jev says goes, including double spaces.

Stump default

        

          Code enforces the mechanical rules first, so Jev never sees an option that breaks them. Then two rounds:
          a screening round of yes/no questions (one per candidate, plus the checks), and a ranking Choice among the
          survivors.
        

        
The rules code enforces

        
    
          
  • Real words only. A letter is offered only if the word can still become one of the 60,000 most common English words, and a word can end only once it is one.
    • 
          
  • Capitals at the start of sentences and lines (code owns case; Jev only picks letters).
    • 
          
  • Spacing: spaces and line breaks only after a word or number, never doubled.
    • 
          
  • Numbers: digits continue, 3.14 and 1,000 work, no letters glued onto numbers.
    • 
          
  • Punctuation only where it fits: no space before a period, apostrophes and hyphens only inside words.
    • 
          
  • No stutters ("sss", "ndndnd") and no word longer than 18 letters.
    •
